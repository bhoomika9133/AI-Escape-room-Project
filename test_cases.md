**Overall result:** **39 passed, 0 failed, 2 skipped** (the two skipped tests are the live-Gemini tests, see section 3)

## 1. How the tests were executed

- **Version 2** is tested directly against its rules engine (`game_engine.py`) and narrator (`game_master.py`). After every adversarial action, the tests check that the authoritative `GameState` is unchanged or changed only as allowed, and that `check_invariants()` returns no violations.
- **Version 1** puts its game logic inside the LLM, so it cannot be tested deterministically through Gemini. Its tests run against:
  - the **offline keyword Game Master** that Version 1 falls back to when Gemini is unavailable;
  - the **system prompt** itself, which contains every solution.

  Where a Version 1 test passes, it confirms the *expected limitation*. The test asserts that the weakness exists.
- **No Gemini API key was available in the build environment.** All results below are from offline mode. Tests that need live Gemini calls were **not executed** (pytest reports them as SKIPPED). They run automatically once `GEMINI_API_KEY` is set.
- Full input/output transcripts for every case are in [`scenario_outputs.md`](scenario_outputs.md). They are generated by `python tools/run_test_scenarios.py`.

**Correct solutions used throughout:**
- clock **3:47**
- radio **1913** kHz
- lamp sequence **RED, AMBER, RED, WHITE**
- final word **ELSIE**

## 4. Errors found during testing and fixed

1. **V2 cabinet puzzle never solved**: `_check_solution` did not handle the `key` puzzle kind, so the walkthrough failed at step 4. A `key` branch was added.
2. **V1 crash on the play screen**: the session key `items` clashed with `st.session_state.items()`. It was renamed to `gm_items`.
3. **V1 offline replies showed raw `[ITEM: …]` tags**: offline replies now pass through the same `parse_tags()` as Gemini replies.
4. **Cross-version module clash in one test process**: a lazy `from game_data import …` inside `GameState.bell_tolls` could pick up Version 1's module. It was changed to a top-level import, and the test helpers purge cached modules.
5. **Ambiguous aliases**: "set" (radio), "up" (hatch) and "light"/"lamp" (lens) caused wrong targets, for example in "set the clock…" or "pick up…". Those aliases were removed.
